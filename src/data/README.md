# Data

The SRS calls for pre-populated JSON/TXT content. Put the team's approved datasets in this folder.

Suggested datasets:
- anime.json
- gaming.json
- movies.json
- tvshows.json
- kpop.json
- comics.json
- manga.json
- characters.json
- events.json
- merchandise.json
- releases.json

Keep content original, royalty-free, or properly licensed as required by the project specification.
