# Team contribution guide

## Before starting
1. Pull the latest `main`.
2. Create a feature branch.
3. Work only on your assigned feature where possible.
4. Reuse shared components.
5. Do not commit `node_modules`.

## Branch examples
- feature/home-foundation
- feature/discovery-search
- feature/content-characters
- feature/events-releases
- feature/store-bookmarks
- feature/chatbot-discovery

## Pull request checklist
- App builds with `npm run build`
- No broken routes
- No unnecessary package additions
- Responsive behavior considered
- Existing shared UI was not unintentionally changed
- Feature is ready for another teammate to review
